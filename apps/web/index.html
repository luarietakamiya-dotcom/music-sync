複数曲をまとめて仕上げる ALBUM / BATCH

完成した曲をまとめて入れ、曲ごとに仕上げた後、音量感をそろえます。STEMの合成とは別の機能です。

完成曲をまとめてドロップ

WAV / FLAC、最大20曲。1曲ずつ処理し、原音は保持します。

現在のモード・仕上がり調整・出力先・有効な参考曲を使います。安全にそろえられる共通の音量を選び、無理な音圧上昇を避けます。

ここに追加した曲は、単体のA/BとSTEMリストを置き換えません。

結果は1曲ずつA/B試聴できます。保存形式・曲情報・ジャケットは下の「音声の保存形式」を使います。無音・クリッピングなどの問題がある曲は個別に保留し、ほかの曲を続けます。

曲をボーカルや楽器に分ける AI STEM SEPARATION · PC専用

PC用の機能です。完成曲やドラム音源から素材を取り出して、1つずつ聴いたり、ミックスを調整したりできます。分離しただけでは現在のOriginal・A/Bを変更しません。

分離する完成曲を1曲ドロップ

WAV / FLAC。読み込んだOriginalをそのまま使うこともできます。

分離する曲を選ぶか、上のOriginalに曲を読み込んでください。

完成曲からボーカル・ドラム・ベース・その他を取り出します。ドラムは1素材です。

分離後は素材ごとに試聴・WAV保存できます。STEMリストに入れた後、「ミックスを作る」で合成できます。

初回はAIモデル約13MBと実行プログラムを取得します。空きメモリは約1.5GB以上が目安です。

処理はこのPC内で行い、音声を送信しません。メモリ8GB以上のPCを推奨します。長い曲では時間がかかります。スマホでは分離済み素材の読み込みなどを利用できます。

素材名はAIによる推定です。音漏れやにじみが残ることがあります。ドラムの各パーツは、キック・スネア・ハイハット・タム・パーカッションと、未割り当て成分の「残りのドラム」です。シンバル・ライド・クラッシュの個別分離には対応していません。

STEMの調整を耳で比較

WAVのみなら最長20分・合成512 MiBまで。FLACを含む場合の合成上限は48 kHzで約4分22秒です。

元のファイルを保持し、素材は先頭から同期します。短い素材の末尾は無音で補います。拍や歌い出しの自動位置合わせ、1曲からの音源分離は含みません。役割・音量・含める設定の変更は「ミックスを作り直す」で反映します。

解析メモ

まだ解析結果はありません。

    LUFS / True Peakは開発中の測定実装です。規格適合認証はありません。DynamicsはLRAではありません。

    Advanced Settings

    通常の仕上げでは操作不要です。手動処理はAUTO / IMPACT / LIVEとは別に適用します。

    音を整える DSP CHAIN / 03

    ゲイン → EQ → リミッター。毎回Aから処理します。設定を変更したら「AからBを生成」を押してください。

    処理設定

    01 / GAIN

    02 / PEAKING EQ

    03 / LINKED LIMITER

    5 ms先読み・左右連動。推定True Peakに応じて追加減衰します。

    Aから新しいBを生成します。適用すると現在のBを置き換えます。

    選択した形式・音質で保存。WAVは元のサンプルレートを維持します。試聴音量や音量マッチは書き出しに含みません。リミッターOFFでは0 dBFS超過があり得ます。

    音量の数値を個別指定 MASTERING / 04

    通常は上の「マスタリングの出力先」で用途を選べます。ここでは原音Aの音量だけを数値で調整します。

    ローカルのルール処理で補正し、結果を再測定します。品質条件を通過した場合だけBを置き換えます。

    仕上がりの目標

    Aを読み込むと補正案が表示されます。

    目標±0.5 LU、減衰合計3 dB以内、クレスト低下3 dB以内などを確認。達成困難な目標は保留します。音色調整や歪み修復は行いません。採用後はA/B比較し、上の「処理済みBをWAV保存」で保存できます。

    自動仕上げの計画・比較・判定

    匿名化しても数値と採否は残ります。解除すると、素材名・説明文を含む詳細版を保存します。
