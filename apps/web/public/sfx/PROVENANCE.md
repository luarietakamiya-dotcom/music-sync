# Music Sync notification sound provenance

This Web distribution includes these three project-owned notification sounds:

- `processing_loop.wav`: playback loop while processing.
- `success.wav`: completion notification.
- `error.wav`: error notification.

They came from the creator-supplied Music Sync
`v2.0.0-alpha.16.5-impact.64_Creative_Mode_Hub_Portable` distribution's
`_internal/assets/sfx` directory. The creator confirmed that they made these
three sounds and authorized their public OSS release with Music Sync under MIT.
The adjacent [LICENSE](LICENSE) is an exact copy of the repository's root MIT
license and applies to these three WAV files.

[README.txt](README.txt) preserves the original Music Sync v1.3 Live Producer
UI Sound Set description unchanged. Its references to `button.wav` and
`start.wav` describe the historic set; those files are not included or covered by
this three-file release. This notice grants no license to other desktop assets,
artwork, application source, plugins or vendor binaries.
