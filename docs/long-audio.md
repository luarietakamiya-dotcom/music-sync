# Long WAV finishing

Drop one PCM or Float32 WAV, select AUTO, IMPACT or LIVE and choose an output target. The file-backed path supports inputs up to 20 minutes and 512 MiB. Original and Processed share a listening position on switch. Loudness matching starts enabled and affects monitoring only. Save B to export the verified Float32 WAV at the original rate, channel count and length.

The Worker reads up to 65,536 frames at a time. AUTO corrects measurable DC offset and sets global gain using integrated loudness and estimated true peak. IMPACT can add gentle presence EQ when crest factor permits. LIVE carries the selected venue's reflection and reverb history across chunks. The output target and available peak headroom determine the final gain. Long mode supports these stages and output targets. Vocal presence, bass, clarity, warmth, punch, width and density now use persistent DSP state across chunks. Local band energy reduces excessive boosts. Existing width, correlation and crest suppress unsuitable additions. External B imports, sound-colour presets and FLAC follow the shorter in-memory workflow. The UI reports actual repair coverage, applied preferences and pending settings. A neutral render dominated by constant gain is identified as a small matched difference.

The Worker measures the mixed song, writes a separate candidate in origin-private browser storage and reads that file back to measure it. The gate checks the complete format, loudness, RMS, peak, clipping, crest, correlation, side energy and DC. A failed check permits one reduced-strength render. The UI commits a candidate only after acceptance. Undo, replacement and cancellation release temporary files. After an interrupted browser session, the next render reclaims abandoned candidates using per-file Web Locks.

Long rendering requires local browser storage with sufficient free space for the candidate and a prior B during replacement. Candidate size is 56 bytes plus four bytes per channel per frame. Playback uses browser media elements and can pause briefly on switch while the decoder seeks.

## Treble restoration

AUTO, IMPACT and LIVE can screen for sustained noise around 9 kHz before mixing. The default adaptive setting and the three intensity limits use the same detector. OFF bypasses it. The Worker checks for broadband, stationary energy over several windows, protects brief attacks and tonal highs, and conditionally applies gentle clarity around 4.75 kHz. The repair must measurably reduce the affected band while preserving presence, body and peaks. An unsuccessful repair is bypassed. Sample rates below 24 kHz bypass this stage. Sustained noisy instruments can resemble hiss. Audition Original and Processed with loudness matching.

The finishing panel also offers harmonic-aware spectral grain attenuation with LIGHT, STANDARD and STRONG intensity and an amount control. A streaming overlap-add transform protects local harmonic peaks and attacks, and attenuates weaker, persistent residual bins between them in roughly the 2–11.5 kHz range. The per-bin attenuation caps are 2/4/6 dB. The candidate is independently analyzed before adoption. Its duration is sample-aligned with the source, including the tail. Quantitative residual reduction is an estimate of the treated spectral floor, not a whole-song noise measurement. Intentional distortion, breathiness and sustained noisy instruments can resemble unwanted grain, so matched audition remains part of the workflow. The treble controls set hiss frequency and cut limit, and enable a bounded presence lift. Combined repairs that fail verification can fall back to an independently measured single correction. Loudness aggression defaults to 35. Lower values restrict gain increases, higher values allow more lift within the original peak and quality limits. Explicit delivery profiles keep their loudness targets.

## Long stem mixes

Drop 2–16 aligned WAVs with the same sample rate. A clearly named vocal/instrumental pair dropped together selects the paired workflow by default. For ambiguous names, select the pair mode and confirm the roles. The Worker measures each track, verifies any proposed instrumental EQ and sums aligned blocks to a separate stereo Float32 WAV. Shorter tracks end in silence. One global true-peak attenuation preserves relative levels. AUTO, matched A/B and WAV export then use the long finishing workflow.

Each input and the rendered mix must fit 512 MiB. Inputs together must fit 1 GiB, and the longest track must fit 20 minutes. Allow browser storage space for A, B and a replacement in progress. Projects containing FLAC retain the in-memory limits.
